# OpenParallel: product truth

## What it is
OpenParallel makes a second (third, …) copy of a desktop app you already have, with its own
login and data, so two accounts of the same app run side by side. Each copy is a launcher and a
data folder; the original app is never modified. Free and open source (MIT), for macOS, Windows
and Linux.

## Who it is for
People who juggle accounts of the same app: freelancers and agencies with several client
workspaces (Discord, Telegram, Claude, VS Code), people keeping work and personal apart,
social and support teams running several WhatsApp Web or Telegram sessions, developers with
separate editor profiles. They are at a desk, mid-work, tired of signing out and in.

## What is uniquely true
- A copy opens from the Dock, Start menu or applications menu like any app, under its own name
  (default: "<App> 2", then "<App> 3"…).
- Honest status per app, never rounded up: Tested (this exact version ran as two copies with
  separate data), Supported (a recipe exists for this kind of app), Experimental, Shares data,
  Not supported. 26 apps / 36 versions tested on macOS as of 2026-10.
- Private by construction: no telemetry, no account, no background service, no network calls
  from OpenParallel itself. Removing a copy moves it to the Trash / Recycle Bin.
- Works with websites too: any site as its own app window with its own cookies.

## Never claim
Uninventable: user counts, reviews, press, benchmarks, "verified" accounts, apps not in the
register, App Store availability, support for single-instance apps (Zoom, Steam, Office).

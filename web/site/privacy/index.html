Privacy

Short, because there is little to say: OpenParallel and this website collect nothing.

The app

OpenParallel doesn’t use the network. It has no account, no analytics, no crash reporting and no update checks. It runs only while you have it open, and it never changes the apps you copy. Your copies talk to their own services exactly as the original app does.

Each copy’s data stays on your computer, in OpenParallel’s own folder. Moving a copy to the Trash (the Recycle Bin on Windows) takes its shortcut and its data with it, and you can restore them from there.

Reports

Report a problem builds a report you can read before anything happens. Sending it opens your own mail app, or a GitHub issue page if you choose that; OpenParallel never sends it for you. The report includes your system and version lines only if you leave that box ticked.

This website

No cookies, no analytics, no tracking pixels and no fonts or scripts from other companies. The page uses your system’s own fonts plus one typeface served from this site. Cloudflare hosts it and keeps the usual short-lived request logs; its optional visitor analytics are switched off.

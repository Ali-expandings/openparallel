Windows and Linux

The same recipes run there: Chromium browsers and Electron apps get their own profile folder, VS Code its own settings and extensions, Firefox its own profile, Telegram its own working folder. Real-app testing on Windows and Linux is under way, so those apps count as Supported until a test says more.

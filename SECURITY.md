# Security

OpenParallel launches other apps on your computer, so security reports matter to us.

## Reporting a problem privately

Please **don't open a public issue** for a security problem. Use GitHub's private reporting instead: the **Security** tab of this repository → **Report a vulnerability**. Include what an attacker could do, the steps to reproduce it, and the OpenParallel version and system you used.

You'll get a reply within a week. Once a fix is released, the report is credited in the release notes unless you'd rather stay anonymous.

## What's in scope

- Anything that lets a copy, a website instance or another program read another copy's data, or the original app's.
- Launchers, shortcuts or desktop entries that could be made to run something other than the app they name.
- Ways OpenParallel could write outside its own folders, modify another app, or delete data permanently.
- Report a problem sending anything without the user choosing to.

## Supported versions

Fixes go into the latest release. OpenParallel has no auto-updater by design; releases are announced on the [Releases](https://github.com/Ali-expandings/openparallel/releases) page and the [website](https://openparallel.pages.dev).
